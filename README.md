# auto-cnpscts

Пайплайн конспектов из презентаций (PDF) через GLM-5.3-Flash (OpenCode Go):
модель извлекает задачи со слайдов (и переписывает начисто готовые решения),
оформляет всё в LaTeX. Чистая теория исключается.

## Использование

Ключ берётся из `.env` в корне проекта или из переменной окружения:

```fish
printf 'OPENCODE_API_KEY=ключ\n' > .env   # если ещё не сделано
```

Одна презентация:

```fish
uv run auto-cnpscts презентация.pdf
```

Пакетный режим (без аргументов): обрабатывает все `*.pdf` из папки
`presentations/`, у которых конспекта ещё нет — конспект определяется
по названию с 1-го слайда или по имени PDF:

```fish
set LIB (nix-build '<nixpkgs>' -A stdenv.cc.cc.lib --no-out-link)
env LD_LIBRARY_PATH=$LIB/lib uv run auto-cnpscts
```

Результат: `presentations/conspecty/<имя PDF>.md` (в пакетном режиме)
или `conspecty/<имя PDF>.md` (когда PDF указан явно). Заголовок внутри md —
название с 1-го слайда; если текст на нём не извлекается, модель распознаёт
его по картинке. Поле даты оставлено пустым.

```markdown
# Название презентации

Дата: 

## Задача 1 *(слайд 3)*
Условие

### Решение
Решение с LaTeX ($x^2$)
```

Заголовки уровня 1–2 из ответов модели срезаются/понижаются, чтобы
структура конспекта не ломалась.

Опции:

```text
--dir DIR         папка презентаций для пакетного режима (по умолчанию presentations/)
--out DIR         папка вывода (по умолчанию conspecty/ рядом с презентациями)
--force           в пакетном режиме перегенерировать всё
--model NAME      модель (по умолчанию glm-5.3-flash; можно OPENCODE_MODEL в .env)
--batch-size N    слайдов на запрос извлечения (по умолчанию 8)
-v                детальные логи
```

## Требования

- `uv` (зависимости ставятся `uv sync`)
- ключ OpenCode Go в `.env` (`OPENCODE_API_KEY`) или в окружении

## NixOS: запуск тестов и CLI

PyMuPDF линкует `libstdc++.so.6`, которого нет в системе. Брать его из `stdenv.cc.cc.lib`:

```fish
set LIB (nix-build '<nixpkgs>' -A stdenv.cc.cc.lib --no-out-link)
env LD_LIBRARY_PATH=$LIB/lib uv run pytest -q
env LD_LIBRARY_PATH=$LIB/lib uv run auto-cnpscts
```

## Тесты

Все запросы к API в тестах замоканы; реальный API дёргается только при ручном прогоне.
